# Установка и запуск проекта ISMME (локально)

Данная инструкция поможет вам развернуть проект локально с использованием **XAMPP** (Apache + MySQL).

## Требования

- Установленный [XAMPP](https://www.apachefriends.org/ru/index.html) (с Apache и MySQL).
- Файлы проекта (текущий репозиторий).
- Файл дампа базы данных (находится в репозитории, обычно с расширением `.sql`).

## Пошаговая инструкция

### 1. Подготовка окружения

1. Запустите **XAMPP Control Panel**.
2. Включите службы **Apache** и **MySQL**, нажав кнопки **Start** напротив каждой.
3. Убедитесь, что порты не заняты (Apache: `80`, MySQL: `3306`). При конфликте измените порт в настройках.

### 2. Размещение файлов проекта

Скопируйте содержимое репозитория (все папки и файлы) в директорию:

C:\xampp\htdocs\wordpress\

> Если нужной папки `wordpress` нет, создайте её вручную.

После этого путь к сайту будет: `http://localhost/wordpress`

### 3. Импорт базы данных

1. Откройте в браузере **phpMyAdmin**: `http://localhost/phpmyadmin`
2. Нажмите на **Создать БД** (слева вверху).
3. Задайте имя базы данных (например, `books_db`). Выберите кодировку `utf8_general_ci` → **Создать**.
4. Перейдите в созданную базу данных.
5. Откройте вкладку **Импорт**.
6. Нажмите **Выберите файл** и укажите файл `.sql` из папки репозитория.
7. Прокрутите вниз и нажмите **Применить** / **Импортировать**.
8. Дождитесь сообщения об успешном завершении.

### 4. Настройка подключения к БД (если нужно)

Если WordPress требует вручную указать данные подключения, отредактируйте файл `wp-config.php` в папке `C:\xampp\htdocs\wordpress\`:

```php
define( 'DB_NAME', 'books_db' );        // имя созданной БД
define( 'DB_USER', 'root' );            // пользователь XAMPP
define( 'DB_PASSWORD', '' );            // пароль (по умолчанию пустая строка)
define( 'DB_HOST', 'localhost' );
